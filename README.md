# 🛒 Amazon Clone Website

A modern, responsive, and feature-packed Amazon Clone built with vanilla **HTML5**, **CSS3**, and **JavaScript (ES6+)**.

![Amazon Clone](https://images.unsplash.com/photo-1607082348824-0a96f2a4b9da?auto=format&fit=crop&w=1200&q=80)

## 🌟 Key Features

- **Amazon-Styled Navigation**:
  - Location delivery selector with dynamic prompt
  - Search bar with department category filter
  - User sign-in & Account state mock
  - Live Cart icon with real-time badge count
- **Responsive Sub-Header**:
  - Slide-out mobile and desktop sidebar navigation (All menu)
  - Quick-access department filters (*Electronics, Fashion, Home, Beauty, Deals*)
- **Hero Image Carousel**:
  - Auto-playing hero carousel with previous/next controls and navigation dots
  - Gradient blend into product dashboard
- **Feature Category Cards**:
  - Quad-image category showcase cards with direct filter links
  - Deal of the day with live countdown clock
- **Horizontal Deal Scroller**:
  - Smooth-scrolling Today's Deals section with left/right navigation arrows
- **Interactive Product Catalog**:
  - Dynamic product grid with star ratings, Prime badges, discount percentages
  - Sort by: *Price (Low/High), Customer Rating, Biggest Discount, Featured*
  - Instant search filtering
- **Interactive Quick View Modal**:
  - Detailed product preview with specs, ratings, and instant purchase options
- **Slide-In Shopping Cart Drawer**:
  - Cart drawer slide-over from the right
  - Quantity adjuster (+/-), remove item, and clear cart
  - Dynamic **Free Delivery Progress Bar** ($35 qualification threshold)
  - Full `localStorage` persistence (keeps items across page reloads)
- **Simulated Checkout Flow**:
  - Order placement modal with auto-generated Order ID and order summary
- **Toast Notification Engine**:
  - Sleek Amazon-style floating notifications for cart and action alerts
- **Full Responsive Design**:
  - Optimized for mobile, tablet, laptop, and 4K desktop screens

## 🚀 How to Run Locally

1. Clone or download the repository.
2. Open `index.html` directly in any web browser (Chrome, Edge, Firefox, Safari).
3. (Optional) Run with **Live Server** extension in VS Code for live reloading.

---

## 🌐 Deploy to GitHub Pages (Free Hosting)

1. Go to your repository on GitHub.
2. Click **Settings** > **Pages** (in the left sidebar).
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Click **Save**. Within 1–2 minutes, your Amazon clone will be live online!
